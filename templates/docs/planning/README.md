# Planning docs: index

Design notes and records for features that are live or built. Finished audits, results, replays, pilots, old plans and handoff notes live in `docs/archive/` (not read by default). Read a doc here only when the task touches that feature. When you add a planning doc, add one line to this index. When its work is finished and nothing live refers to it, archive it with `git mv`.
